# Статья AI Native Company

`index.html` — собранная страница для публикации. Редактировать нужно файлы в
`src/`, а не сам `index.html`.

Собрать страницу:

```bash
cd Data/AINativeCompany
node build.mjs
```

Проверить, что `index.html` соответствует исходникам, ничего не перезаписывая:

```bash
node build.mjs --check
```

У сборки нет пакетных зависимостей. Она рекурсивно раскрывает директивы такого
вида:

```html
<!-- @include "article/act-1/problems/03-result-cost.html" -->
```

Пути считаются относительно файла, в котором находится директива. Включения
раскрываются во время сборки, поэтому результат остаётся одной автономной
HTML-страницей и по-прежнему работает и через GitHub Pages, и через `file://`.

## Структура исходников

- `src/page.html` — каркас документа и точка входа сборки.
- `src/layout/` — обложка, навигация и подвал.
- `src/article/` — композиция статьи.
- `src/article/act-1/problems/` — отдельный файл для каждой из 15 проблем.
- `src/article/act-1/` — акт I, пять групп и общая причина.
- `src/article/act-2/` — Multica и три раздела акта.
- `src/article/act-3/` — внедрение и шесть разделов акта.
- `src/styles/` — шесть существующих слоёв стилей.
- `src/scripts/` — три существующих блока JavaScript.

Каждому пункту оглавления соответствует отдельный исходный файл. Родительские
разделы содержат директивы включения, поэтому порядок чтения виден прямо в
структуре файлов.
